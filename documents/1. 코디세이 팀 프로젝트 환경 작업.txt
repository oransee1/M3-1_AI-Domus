# AI 기반 개인화 학습 코치 서비스

## 프로젝트 소개
사용자의 학습 목표와 진행 상황을 파악하여 맞춤형 학습 계획을 수립하고,
일일 학습 리마인더와 진도 체크를 제공하는 AI 학습 코치 서비스입니다.
RAG를 통해 학습 자료를 검색하고, Long-term Memory로 사용자별 학습 이력을 관리합니다.

| 이름 | 역할 | 담당 업무 |

## 기술 스택
- **AI**: OpenAI API, LangChain, Pinecone (Vector DB)
- **Backend**: FastAPI, Render
- **Frontend**: HTML, CSS, Javascript
- **Infra**: Vercel, Supabase, GitHub Actions
- **자동화**: n8n (일일 리마인더 발송)

## 시스템 아키텍처
(아키텍처 다이어그램 이미지)

## 핵심 AI 활용

### 1. AI Agent 구조
- Planning Agent: 사용자 목표 분석 → 학습 계획 수립
- Coaching Agent: 일일 진도 체크 → 피드백 생성

### 2. RAG 파이프라인
- 학습 자료 임베딩 → Pinecone 저장
- 사용자 질문 → 관련 자료 검색 → 맥락 기반 답변

### 3. Long-term Memory
- 사용자별 학습 이력, 선호도, 강점/약점 저장
- 대화 시 이전 맥락 자동 로드

1. 기획 의도
문제 정의 (Problem Definition)
'천사와 춤을', 'Gentle Mind'와 같이 일관된 분위기의 힐링·뉴에이지 음악 콘텐츠를 지속적으로 발행해야 하는 유튜브 채널의 경우, 콘텐츠 양산 속도가 채널 성장의 핵심입니다. 하지만 현재의 제작 방식은 Suno에서 음원을 생성하고, 외부 AI 이미지 툴(구글 Flow 등)에서 커버용 3x3 스토리보드 이미지를 만든 뒤, 이를 일일이 분할하여 캡컷(CapCut)과 같은 영상 편집기에서 타임라인 싱크를 맞추고 렌더링하는 등 수작업에 극심한 병목이 발생하고 있습니다.

타겟 사용자 (Target Audience)

오리지널 BGM, 수면 음악, 로파이(Lo-Fi) 등 음악 기반의 유튜브 채널을 운영하는 1인 크리에이터

영상 편집 기술이나 프롬프트 엔지니어링 지식이 부족하지만 고품질의 음악 영상을 대량으로 제작하고자 하는 사용자

AI 활용 방식 및 기술적 접근 방식

AI 오케스트레이션: 무료 Gemini API를 활용해 사용자의 단순한 한국어 입력(분위기, 장르 등)을 각 AI 생성기에 최적화된 영문 프롬프트로 자동 변환합니다.

멀티모달 에이전트 연동: Apiframe을 통해 Suno(오디오) 및 Nano Banana 2 Lite(이미지) API를 호출하여 멀티모달 에셋을 동시 생성 및 다운로드합니다.

로컬 데스크톱 자동화 (PyQt5): 다운로드된 에셋의 씬 분할부터 최종 영상 렌더링(17~20분 소요)까지 전 과정을 PyQt5 기반의 단일 프로그램 내에서 백그라운드로 자동 처리하며, 최종적으로 .exe 실행 파일 형태로 패키징하여 누구나 쉽게 설치 및 사용할 수 있도록 배포합니다.

2. 프로젝트 내용
본 프로젝트는 복잡한 다단계 미디어 제작 과정을 하나의 데스크톱 소프트웨어로 통합하는 원스톱 AI 워크플로우 자동화 서비스입니다.

핵심 AI 활용 방식 (필수 기술 요소 3가지 충족)
AI Agent (기획 및 실행 에이전트 연계)

Prompting Agent (Gemini): 사용자의 의도(장르, 무드, 가사 유무)를 분석하여 Suno 전용 음악 프롬프트와 Nano Banana 2 Lite용 3x3 그리드 프롬프트를 동시 기획·생성합니다.

Execution Agent: Apiframe 플랫폼을 통해 Suno Agent와 Nano Banana 2 Lite Agent에 생성 명령을 내리고, 완료 여부를 모니터링하여 결과물(mp3, png)을 로컬 환경으로 수집하는 역할을 수행합니다.

멀티모달 AI (Multimodal AI)

단일한 텍스트 입력(기획 의도)을 바탕으로 청각적 요소(Suno)와 시각적 요소(Nano Banana)를 동시에 생성하고, 이를 영상(mp4)이라는 하나의 완성된 멀티모달 콘텐츠로 결합합니다.

자동화 워크플로우 (Automated Workflow)

사용자의 [실행] 버튼 클릭 한 번으로 프롬프트 번역 및 생성 → API 호출 및 대기 → mp3/이미지 다운로드 → 이미지 9분할 크롭 → 오디오 싱크 맞춤 및 영상 렌더링에 이르는 전체 파이프라인을 인간의 개입 없이 자동화합니다.

시스템 아키텍처 및 구현 설계
Frontend (UI/UX)

PyQt5 GUI: 직관적인 사용자 입력창(분위기 텍스트 박스, 장르 드롭다운, 가사 유무 체크박스), API 키 입력 설정창, 렌더링 진행률(Progress Bar) 및 로그 콘솔 제공.

Backend (로직 및 통신)

API 통신 모듈: google-genai 패키지 및 requests 기반의 비동기 Apiframe REST API 호출.

멀티스레딩 (QThread): 장시간(17~20분) 소요되는 영상 인코딩 중 UI가 멈추지 않도록 워커 스레드(Worker Thread) 분리.

Media Processing

이미지 전처리: OpenCV 또는 Pillow를 활용한 3x3 이미지 자동 9등분 슬라이싱.

영상 합성 엔진: FFmpeg(또는 MoviePy)를 활용해 분할된 9장의 이미지를 음원 길이에 맞춰 배분하고, 화면 전환 모션 적용 후 1080p 해상도의 유튜브 업로드용 mp4로 최종 인코딩.

버전 관리 및 배포

모든 소스코드는 GitHub를 통해 관리(버전 관리 기록 필수 요건 충족).

PyInstaller를 사용해 단일 .exe 파일로 빌드하여 외부 사용자(최소 5명)에게 배포하고 실사용 테스트 및 피드백(UI 편의성, 렌더링 속도 등)을 수집합니다.

3. 기대효과 및 활용방안
기대효과
획기적인 공수 절감 및 생산성 극대화: 프롬프트 작성, 파일 수동 다운로드, 캡컷 타임라인 편집 등에 소요되던 작업 시간(건당 1시간 이상)을 '키워드 입력 후 렌더링 대기' 수준으로 압축하여 1인 크리에이터의 업무 피로도를 대폭 낮춥니다.

데스크톱 기반의 안정성과 접근성: 웹 서버 유지비용 없이 사용자 PC의 자원을 활용하여 렌더링하므로 운영 비용이 절감되며, .exe 배포를 통해 복잡한 파이썬 환경 설정 없이 누구나 쉽게 자동화 툴을 도입할 수 있습니다.

일관된 채널 브랜딩: Gemini API가 음악과 이미지의 톤앤매너를 일치시키는 프롬프트를 작성하므로, 시청자에게 시각과 청각이 완벽히 조화된 고품질 콘텐츠를 안정적으로 제공할 수 있습니다.

활용방안
콘텐츠 무인 자동화 공장: UI의 '예약 생성'이나 '연속 생성' 기능을 차후 추가하여, 잠을 자거나 외출한 사이에도 유튜브 업로드용 영상 파일 수십 개를 로컬 폴더에 자동 적재하는 시스템으로 활용할 수 있습니다.

다양한 영상 규격(숏폼) 확장: 기본 FHD(16:9) 영상뿐만 아니라, 렌더링 모듈 옵션을 추가해 생성된 9장의 이미지를 9:16 비율의 숏폼(YouTube Shorts, TikTok) 전용 세로형 영상으로 자동 변환 및 활용할 수 있습니다.

SaaS 또는 상용 소프트웨어 발전 가능성: 수집된 실사용자 피드백을 바탕으로 UI/UX를 개선하고 라이선스 관리 기능을 추가하면, 타 크리에이터들을 위한 유료 설치형 솔루션으로 비즈니스 모델을 확장할 수 있습니다.
